# المشروع الأول — موقع عرض مشروع العطور

موقع ثابت (HTML + CSS + JavaScript) بدون أي أدوات بناء. افتح `index.html` في المتصفح مباشرة وسيعمل.

## الهيكل

```
first-project/
├── index.html            ← محتوى الصفحة (النصوص والأقسام)
├── README.md
├── assets/
│   ├── favicon.svg       ← أيقونة التبويب
│   └── images/           ← ضع صورك المحلية هنا
├── css/
│   ├── tokens.css        ← الألوان والخطوط والأبعاد (ابدأ من هنا لتغيير الهوية)
│   ├── base.css          ← إعادة الضبط وسلّم الطباعة
│   ├── layout.css        ← شريط التنقل والأقسام والتذييل
│   ├── hero.css          ← الواجهة والزجاجة التفاعلية
│   ├── components.css    ← الأزرار، البطاقات، الجدول، المعرض، العقبات والحلول
│   └── responsive.css    ← الجوال والتابلت
└── js/
    ├── config.js         ← بيانات صور المعرض وعناوينها
    ├── nav.js            ← قائمة الجوال + إبراز القسم الحالي
    ├── gallery.js        ← معرض الصور
    ├── spray.js          ← تفاعل الزجاجة (ضغط الذراع والرذاذ)
    ├── reveal.js         ← الظهور التدريجي
    └── main.js           ← تشغيل الوحدات
```

## التعديلات الشائعة

| أريد أن... | أين أعدّل |
|---|---|
| أغيّر نصًا أو أعيد ترتيب الأقسام | `index.html` (كل قسم داخل `<section>` مستقل، يمكن نقله كاملًا) |
| أغيّر لون الذهبي أو الخلفيات | `css/tokens.css` |
| أبدّل صور المعرض أو أضيف صورة | `js/config.js` |
| أغيّر أرقام الجدول | `index.html` داخل قسم `#finance` (وعدّل عرض الأشرطة `--w` فوق الجدول) |
| أغيّر الخط | وسم الخط في `<head>` داخل `index.html` + `--font` في `tokens.css` |

## ملاحظات

- الأقسام تتناوب بين داكن وفاتح عبر الصنفين `theme-dark` و`theme-light` على وسم `<section>`.
- الخط (IBM Plex Sans Arabic) والصور تُحمَّل من الإنترنت. بدون اتصال يعمل الموقع بخطوط النظام.
- الموقع يدعم القارئات الشاشية، والتنقل بلوحة المفاتيح (حتى ضغط الذراع بزر المسافة)، ويحترم إعداد تقليل الحركة.
